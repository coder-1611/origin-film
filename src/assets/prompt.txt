Build a 3-minute film called ORIGIN: 13.8 billion years in one unbroken camera move,
from the Big Bang to a person typing this prompt. Write everything from scratch in
HTML/JS/GLSL, render it to MP4, and synthesize all of the audio in code. You may not
use API keys, stock footage, stock music, audio samples, or video frameworks (no
Remotion, no HyperFrames). Write the renderer yourself. Work autonomously and don't
ask me questions. Project lives at /Users/sohamsthitpragya/Projects/origin-film/
(renders/ and frames/ are gitignored).

## Core architecture (non-negotiable)
- Every frame is a PURE FUNCTION of t. No requestAnimationFrame timing, Date.now,
  setTimeout, or Math.random. Use a seeded PRNG/hash so the same t gives the same pixels.
- ONE source-of-truth file, timeline.js, holds the tempo map, key/chord changes,
  every note event, every chapter boundary, every camera keyframe and every SFX cue.
  The music and the visuals both import it, so sync comes from shared data, not
  from lining things up by hand.
- Page exposes window.__seek(t) → Promise that resolves once that frame is fully drawn.
- render.mjs: Puppeteer + real Chrome (GPU, not SwiftShader: assert the
  WEBGL_debug_renderer_info string), N parallel workers splitting the frame range,
  resumable (skips frames already on disk), then ffmpeg → 1920x1080, 60fps,
  H.264 CRF 16, yuv420p, AAC 320k.
- Fonts are downloaded locally and awaited (document.fonts.ready) before any frame is captured.
- The same code also runs as a LIVE player (index.html): real-time playback with
  live Web Audio, a scrub bar with chapter markers, space/arrow keys, and a toggle
  that shows the current t, frame number and bar:beat.

## The film: 8 chapters with NO hard cuts
Each chapter must hand off to the next through a match-move, a scale dissolve,
or an object that turns into the next scene's object. Each chapter also has to use
a different rendering technique, so the film shows off a new one every 20 seconds.

I.   0:00–0:12  SINGULARITY: raymarched GLSL void, one point of light, sub-bass drone.
                Title in kinetic type, animated per glyph.
II.  0:12–0:32  INFLATION: 200k+ GPU particles (curl noise, color = temperature)
                that explode exactly on the first downbeat after 1.5s of silence.
III. 0:32–0:58  FIRST LIGHT: volumetric fbm nebula with god rays, then a spiral galaxy
                built from density-wave particles. We dive into one star.
IV.  0:58–1:22  ACCRETION: Three.js protoplanetary disk. Earth forms, then Theia
                hits it (shockwave, debris ring, the Moon forms). Bloom, DOF, film grain.
V.   1:22–1:46  PALE BLUE: procedural planet shader (terrain, oceans with specular
                glints, atmospheric scattering, cloud layer). Camera plunges through
                the atmosphere into the sea.
VI.  1:46–2:14  LIFE: reaction-diffusion cells that divide, then an L-system forest
                growing leaf by leaf, then boids (fish schools that become bird flocks).
VII. 2:14–2:40  FIRE TO FIBER: SVG line-drawings that draw themselves on (fire, wheel,
                printing press, engine), then night-Earth city lights with glowing
                great-circle arcs connecting cities.
VIII.2:40–3:00  THE PROMPT: a laptop in a dark room, a code editor, this exact prompt
                being typed, a render progress bar, and then the screen shows THIS
                film playing (a real recursive Droste effect: feed the rendered canvas back
                in, don't fake it). Zoom into the screen and land on frame 0.
                The last frame must equal the first, so the MP4 loops seamlessly.

A HUD runs throughout: a monospace year counter ("13,799,999,xxx years ago") that
ticks down on a log scale and hits "now" on the last keystroke.

## The score, all synthesized in code (OfflineAudioContext → WAV)
- An original composition with a tempo map (free-time drone → 84 BPM → 120 BPM by
  chapter VII → a ritardando back into the drone). It starts in D minor, moves to
  F major at PALE BLUE, and resolves back to D so the loop is seamless.
- A 5-note leitmotif first heard at the Big Bang that comes back re-orchestrated:
  sine → FM bells (stars) → marimba (life) → supersaw lead (humanity) → solo piano-ish
  pluck (the prompt).
- Instruments: synthesized kick/snare/hats, Karplus-Strong plucked strings, FM bells,
  supersaw pads, a sub bass, risers, and impacts. Reverb is a convolution with a
  procedurally generated impulse response. Add sidechain ducking from the kick and
  a master glue compressor plus a limiter.
- Sound design tied to picture events from timeline.js: the Theia impact is layered
  (sub drop + noise burst + a long tail), each star birth is a bell pitched to the
  current chord, fire gets synthesized crackle, and every typed character in chapter
  VIII gets its own keyclick. Pan every sound by its on-screen x position.
- After the WAV renders, analyze it into per-frame features (32-band FFT + RMS +
  onsets) → audio-features.json. The visuals react to BOTH the symbolic note data
  and the analyzed spectrum.
- Master to −14 LUFS integrated, true peak ≤ −1 dBTP.

## Process
